# Aviaj Landing Page

This repository contains the landing page for **Aviaj**, a premium AI-powered business travel and expense management platform designed for the modern enterprise.

## Features
- **Modern Responsive Design**: Built with a corporate modernism aesthetic, high-contrast layouts, glassmorphic overlays, and harmonized vibrant colors.
- **Interactive Booking Widget**: Experience booking trips, managing cards, team offsites, and viewing reports.
- **AI Insights & Auto-Reconciliation**: Visual showcase of automated workflows.
- **Optimized Performance & Animations**: Beautiful micro-animations and scroll-driven reveal transitions.

## Tech Stack
- HTML5
- TailwindCSS (Utility styles)
- Vanilla JavaScript
- Google Fonts (Inter, Plus Jakarta Sans)
- Material Symbols (Icons)
